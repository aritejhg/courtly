# Security policy

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/aritejhg/courtly/security/advisories/new). Do not open a public issue.

Include the affected commit, steps to reproduce, and the impact. Do not include real Telegram messages, session strings, or other people's personal data.

Only the latest commit on `main` is supported. This is a hobby project, so there is no response-time commitment.

If you find exposed credentials or personal data in this repository, report it the same way. To ask for a listing or message to be removed, see [Responsible use](README.md#responsible-use).
